# THE VIBE CO. ⚜️
### Premium Event Orchestration & Service Hub

THE VIBE CO. is a premium platform designed for managing high-end event inquiries and professional service provider bookings.

## 🌟 Key Features

- **Unified Dashboard**: Manage profile, notifications, and event history in a single, elegant interface.
- **Service Member Hub**: Connect directly with photographers, caterers, and event organizers.
- **Premium Aesthetics**: A sleek, matte black and gold design language for a high-end feel.
- **Real-time Communication**: Integrated chat between clients and service providers.
- **Automated Workflows**: PDF generation for inquiries, email/WhatsApp notifications, and status tracking.

## 🛠 Tech Stack

- **Frontend**: React.js, Framer Motion, Axios, React Icons.
- **Backend**: Node.js, Express.js, MongoDB (Mongoose).
- **Security**: JWT Authentication, Bcrypt password hashing.
- **Communication**: PDFKit, Email Service, WhatsApp/SMS Integration.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14+)
- MongoDB

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```

2. Install dependencies for the root, backend, and frontend:
   ```bash
   npm install
   cd leela\ file/the-vibe-co/backend && npm install
   cd ../frontend && npm install
   ```

3. Configure environment variables (`.env`) in the backend folder.

4. Run the application:
   ```bash
   # From the root
   npm run dev
   ```
